# autoreport-etl

Выгрузка рекламных данных AutoReport (Astana Motors) в Cloudflare D1 — задания GitHub Actions.
Репозиторий публичный только ради безлимитных бесплатных минут Actions.

**Здесь нет ключей и токенов.** Секреты лежат в GitHub Secrets и в Google Таблицах.
Журналы запусков публичны, поэтому все скрипты запускаются через `etl/quiet.mjs`: в журнал GitHub идёт только код завершения,
а подробный журнал пишется в базу D1 (таблица `etl_logs`).

Нельзя печатать расход, конверсии и названия дилеров в журнал напрямую (`console.log` вне `quiet.mjs` допустим
только в `etl/guard.mjs`). Новые задания запускайте так: `node etl/quiet.mjs etl/имя.mjs`.
